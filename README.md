# 🎮 Jogo da Velha

Este projeto é uma implementação do clássico **Jogo da Velha (Tic-Tac-Toe)** utilizando **HTML, CSS e JavaScript**.

---

## 🚀 Funcionalidades
- Dois jogadores se alternam nas jogadas
- Verificação automática de vitória ou empate
- Reinício do jogo sem recarregar a página
- Interface simples e responsiva

## 📂 Estrutura de pastas
- `index.html` → Estrutura principal do jogo
- `style.css` → Estilização da interface
- `script.js` → Lógica do jogo (turnos, checagem de vitória, reinício)

---

## ▶️ Como executar
1. Clone este repositório:
2. Abra o arquivo index.html em qualquer navegador
